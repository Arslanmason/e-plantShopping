# Paradise Nursery

A React-based shopping application for houseplants. This project demonstrates front-end web development skills including component creation, state management with Redux, and dynamic UI rendering.

## Features
- **Landing Page**: Welcomes users to Paradise Nursery.
- **Product Listing**: Displays various houseplants categorized by type (Air Purifying, Succulents, Ferns).
- **Shopping Cart**: Allows users to review selected items, adjust quantities, delete items, and view total costs.
